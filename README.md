# Tidebound Corridor

An opera-themed browser game: an endless corridor, a story, a harbour to rebuild, and more.

**Play:** https://davidgoncalveswhs.github.io/tidebound-corridor/

Progress is saved in your own browser (nothing is sent anywhere). Use Settings to clear it.

The Rival Stage (local two-player) works on your own network. For short room codes run `python3 serve.py` and open the game from the address it prints; the hosted page uses the longer code.

**All games:** https://davidgoncalveswhs.github.io/tidebound-corridor/games/
