# Tidebound Corridor

An opera-themed browser game: an endless corridor, a story, a harbour to rebuild, wishes, and a third-person war.

**Play:** https://davidgoncalveswhs.github.io/tidebound-corridor/

- **The Drowned Front** (third-person war, desktop) is launched from the main menu's Play tab. Its results are paid into the main game the next time you open the menu.
- Progress is saved in your own browser (nothing is sent anywhere). Use Settings to clear it.
- The Rival Stage (local two-player) works on your own network. For short room codes run `python3 serve.py` and open the game from the address it prints.
